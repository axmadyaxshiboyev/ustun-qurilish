# Ustun Qurilish

Qurilish kompaniyasi uchun konsept sayt. Sahifa aylantirilganda 3D bino chizmadan boshlab besh bosqichda quriladi: loyiha, poydevor, karkas, fasad, topshirish.

- Bitta statik sahifa: `index.html`, build bosqichi yo'q
- 3D sahna: three.js r128 (`three.min.js`)
- Shrift: Helvetica Neue (tizim shrifti; yo'q qurilmalarda Helvetica yoki Arial)
- Suratlar: Unsplash (Dmytro Yarish, Tinky 小天, Sebastian Schuster, Marcus Lenk, Sir. Simo)

Kompaniya, raqamlar va aloqa ma'lumotlari o'ylab topilgan. Forma hech narsa yubormaydi.

Dizayn va ishlab chiqish: Ahmadjon Yaxshiboyev
